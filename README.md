# AL-SANE PRO – السّناي برو

تطبيق Android عربي لإدارة المتجر والمخزون محليًا دون إنترنت.

## ما تم تنفيذه في النسخة التأسيسية
- واجهة عربية أولية بألوان كحلية وذهبية.
- قاعدة بيانات Room دائمة على الهاتف.
- إضافة المنتجات وعرضها وحذفها.
- عرض عدد المنتجات وقيمة تكلفة المخزون.
- التحقق من إدخال أسعار وكميات غير سالبة.
- إعداد GitHub Actions لبناء APK وتشغيل اختبارات الوحدة.

## تنبيه مهم
هذه ليست بعدُ النسخة المحاسبية التجارية المكتملة. المبيعات والمشتريات والمرتجعات والعملاء والموردون والديون والصندوق والتقارير والصلاحيات والتشفير والنسخ الاحتياطي تحتاج إلى تنفيذ واختبارات إضافية قبل استخدامها في متجر حقيقي.

## البناء
يتطلب JDK 17 وAndroid SDK 35:
```bash
gradle assembleDebug
gradle testDebugUnitTest
```
عند نجاح GitHub Actions ستجد ملف APK في Artifacts ضمن تشغيل workflow.
