# محاسبي – تطبيق إدارة المتجر والمخزون

تطبيق Android عربي يعمل محليًا دون اتصال، مبني باستخدام Kotlin وJetpack Compose وRoom.

## المنفذ حاليًا
- واجهة عربية وهوية كحلية وذهبية.
- قاعدة بيانات Room محلية دائمة.
- إضافة المنتجات وتعديلها وحذفها.
- البحث بالاسم أو الرمز.
- حفظ سعر الشراء والبيع والكمية والوحدة وحد التنبيه.
- منع القيم السالبة والتحقق من تكرار رمز المنتج.
- ملخص عدد المنتجات وقيمة تكلفة المخزون والمنتجات منخفضة المخزون.
- GitHub Actions لبناء APK وتشغيل اختبارات الوحدة ورفع APK كـ Artifact.

## حدود هذه النسخة
هذه نسخة تأسيسية لإدارة المنتجات والمخزون، وليست بعدُ نظامًا محاسبيًا مكتملًا. لم تُنفذ بعد وظائف البيع والشراء والمرتجعات والعملاء والموردين والديون والمصروفات والصندوق والتقارير المتقدمة وتعدد المستخدمين والتشفير والنسخ الاحتياطي. لا تستخدمها وحدها لإدارة حسابات متجر حقيقي قبل تنفيذ هذه الوحدات واختبارها.

## البناء
المتطلبات: JDK 17 وAndroid SDK 35 وGradle 8.9.
```bash
gradle --no-daemon assembleDebug
gradle --no-daemon testDebugUnitTest
```

## الحصول على APK
بعد كل Push إلى فرع `main` يبدأ GitHub Actions تلقائيًا. افتح تبويب **Actions**، ثم افتح أحدث تشغيل ناجح، ومن قسم **Artifacts** نزّل `Mohasabi-debug-apk`.

## البناء من الهاتف
1. افتح المستودع في GitHub.
2. انتقل إلى **Actions**.
3. افتح سير عمل **Build Mohasabi APK**.
4. اضغط **Run workflow**.
5. انتظر نجاح البناء، ثم نزّل Artifact من صفحة التشغيل.
